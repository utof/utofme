# utofme

Personal site + portfolio.

## Stack

Astro 6 · Svelte 5 (runes) · Cloudflare Workers (Assets) · Bun · TypeScript strict.

## Layout

```
packages/
├── site/   ← Astro + Svelte app
└── specs/  ← specs, plans, ADRs, templates
```

Requires Bun ≥ 1.2 and Node ≥ 22.12 (Astro 6 requirement).
