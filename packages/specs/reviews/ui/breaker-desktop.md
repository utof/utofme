# UI review — breaker-desktop

**Scope:** desktop viewports 1280×800 @DPR1 and 1920×1080 @DPR2. Lens: a picky visitor who clicks around and reports what looks off or is broken.

## Verification caveat (read first)

- **The live site could not be reviewed.** `https://utofme.vip-ilyabondar.workers.dev` returned `CONNECT 403` from the session's egress proxy (policy denial, logged as `connect_rejected`). Per the proxy README, policy denials are reported rather than routed around, so I did not try other paths.
- **Instead I built `origin/main` (6fa1755) locally** with `UTOFME_FIXTURES=false`, the same flag `.github/workflows/deploy.yml` sets for production. The leak guard `check:no-fixtures` passed on that build (23 pages, 7 published works). I served it with `astro preview` on 127.0.0.1:4321.
- Consequences: findings describe the production build as built from main, but they are not confirmed on the live deploy. `astro preview` does not apply `public/_redirects`, so `/works/` shows 404 locally (see B-07).
- A first pass used a default build with fixtures included (`UTOFME_FIXTURES` defaults to `true`). That build was discarded; its fixture pages are not reported.

## Method

- Crawled 52 routes at both viewports: home, the 7 published works, 6 garden notes, `/garden/`, `/garden/graph/`, the 4 slash pages, `/stats/`, `/search/`, `/lab/datamosh/`, both feeds, `/works/`, and a junk URL for the 404 page. Recorded HTTP status, console errors, page errors, failed or 4xx/5xx requests, broken images, video `readyState` and `currentSrc`, horizontal overflow, and text-edge alignment. Scrolled each page to trigger lazy media.
- Interaction scripts covered: home card click → morph → project → Back (scroll and focus), prev/next, Pause motion across navigation and reload, Ctrl+K palette (open, type, Enter, Esc), Tab order and focus ring on home, and search for "linsae" and a no-hit query.
- External-link HEAD checks were not run; the only external hosts seen were GitHub and webmention.io links, and `example.com` in the welcome note.

## Checked and fine (desktop)

- **No horizontal overflow** on any of the 52 routes at 1280 or 1920 (`scrollWidth ≤ innerWidth`).
- **All 7 published works load.** Their home card videos reach `readyState=4` (`768` px AV1, correct for cards). No broken images except the `example.com` avatar (B-06).
- **Morph ratio:** the project banner renders at 3.00:1 on desktop (1216×405), as specified.
- **Back after morph:** returns to `/` with scroll 0 and focus on the clicked card's link.
- **Pause motion persists:** `data-motion="paused"` survives navigation to a project and a full reload; the label reads "Play motion" and `aria-pressed="true"`; loop videos are `paused=true`.
- **Prev/next** on `/works/tactical-arena/`: "All projects" → `/`, "ADS1299 Learning Lab →" → `/works/eeg-ads1299-lab/`.
- **Search** for "linsae" returns `/works/linsae/`; a no-hit query shows "No results for …" with the expected chrome.
- **Keyboard:** Tab reaches Pause motion first, then the cards, then the footer links, and each has a visible focus ring (`box-shadow` 2 px blue).
- **Footer on home** is aligned (x=96), matching the masonry.
- **Fixture leak guard** (`check:no-fixtures`) passes on the production-equivalent build.
- Garden math (KaTeX) fonts show as "unloaded" until used. This is expected lazy loading, not a bug.
