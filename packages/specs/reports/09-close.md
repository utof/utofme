## 3. Footer layout bug
Cause: `_BaseLayout.astro` rendered `<HCard />` and `<SoundToggle />` as bare `<body>` children, so they had no inset (h-card at x=0, button at x=0–32) while `<footer>` has `padding-inline: var(--footer-inset, var(--space-3))`. Fix: wrap both in `.footer-meta` (flex, `justify-content: space-between`, same `padding-inline`, h-card left, sound button right under the footer's "source" edge); `.footer-meta + footer` trims the doubled gap. `HCard.astro` markup is unchanged, so microformats stay intact (checked by the new e2e and the existing `microformats` suite). `/` (minimal) still hides the h-card and has no sound button, by design (ADR 0040).

Measured before → after (mobile 393 px / desktop 1280 px): h-card x 0 → 12; sound button 0–32 → 349–381 / 1236–1268; "© utof" starts at 12 on both. Checked `/`, `/works/tactical-arena/`, `/now/`, `/garden/`. New e2e: `footer.spec.ts › footer identity block aligns with the footer on …` (3 routes).
