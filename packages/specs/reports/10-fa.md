## Decisions and doubts

1. **Event columns.** In the notes data `kill` and `damage` rows have `pid` = the victim and `pid2` = the attacker, and `alive[t]` is already 0 at the kill tick. Marker labels read "Defender 2 eliminates Attacker 1".
2. **Autoplay starts from tick 0** (the whole round once, at 1×); the static default is the board at first contact (spec: "default / claim"). A user Play starts from the current position. Any user action cancels autoplay for good and stops it if it was running (reducer in `replay.ts`).
3. **Pause motion** stops playback at once; the user can still press Play, and drawing is then tick-stepped (positions round to whole ticks).
4. **One marker button per event tick.** The two kills at tick 24 share a button (12 buttons for 13 events) because their hit areas would coincide; the "Events" list shows all 13.
5. **Ghosts** exist only for living enemies that were seen earlier and are not seen now, at their last seen place.
6. **Stamp text.** Lane A2's `Stamp` prints "as measured on …", so the Block passes `block 28 (5v5), self-play, recorded 2026-11-04` (date from the notes data README); the spec's literal "Agents: block 28 …" would read "as measured on Agents: …". `Stamp` has `white-space: nowrap`, so the line is wider than the column on a 393 px phone (the page does not scroll sideways; asserted). Issue for A2: allow wrapping.
7. **`motionState()` is not SSR-safe** (it touches `document` when called, lane S). The island creates it in `onMount`; calling it at component top level crashes the server render. Issue for S: guard it or document it.
8. **AC3.5 on the lab page.** The lab figure sits inside the first viewport (plus 200 px) on a phone, so "no request before scrolling" cannot be shown there; lane I tests it on the article, where F1 is further down.
9. **Lazy-data column reads 0.0 KB** for `/lab/figures/replay/` although the island fetches a 1.9 KB gzip file: lane B's scan follows JSON names inside JS chunks, but the URL reaches the island through `props` in the HTML. Issue for B/I (spec: "sum of the route's referenced `dist/_astro/*.json`").
10. **The sync fixture is the real round 0** (path-like fields replaced by stand-ins), 32 KB after Biome formatting.
11. **Test environment.** `astro preview` daemonizes: the first Playwright run starts it and fails with "webServer exited early", later runs reuse it. It keeps serving this worktree's `dist` on 4321 until stopped, so it was stopped (`astro preview stop`) after the last run; other lanes should do the same under the lock.
12. Review the two `@visual` snapshots on the first baseline render: the canvas text uses the platform sans-serif font for the site letters.
