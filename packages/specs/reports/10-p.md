## Deviations and decisions (recorded in ADR 0059)

1. **Code spans are not prose.** The credits must name the datasets (`cs2povarchive/cs2-demos`, `blanchon/opencs2_dataset_demo`) and their licences, which contain digits. They are written as code spans and the lint drops code spans, instead of a growing name list. `pass.mdx` has a case.
2. **`$$` maths is outside the digit rule** (its constants are definitions); inline `$…$` maths is not used.
3. **Exemptions**: `[Bb]lock N` (sentence-initial "Block 28" in a caption); years limited to 2000–2039 so a count like 2048 cannot pass as a year.
4. **`Note` is a prose container** in the shared reader (its tags go, its children stay paragraphs), and **`EloSentenceBlock` is an inline prose token**, not a figure (it has no number). `parseMdxProse` output is unchanged for A1's tests (`mdx-prose.test.ts` green).
5. **F9 try line**: the spec's "Drag the rounds down to 1,000, then pick one seed." has a bare number with no key; the page says "Drag the rounds all the way down, then pick one seed." (1,000 is the slider's minimum, so the action is the same). FD's e2e should follow this wording.
6. **Headings** are forced by the ids (slugs must equal them): "Ten seconds", "A board", "Learning", "Practice maps", "Measured honestly", "Stronger, not more CS", "Notebook", "Toward real CS2", "Methods". The TOC titles are the same strings.
7. **Stamps** sit between em dashes, not parentheses, because of Doubt 2.
8. Credit links checked this turn (all HTTP 200; arXiv titles and the Bradley–Terry DOI checked via Crossref): HF datasets ×2, JAX, JaxMARL, PPO 1707.06347, IPPO 2011.09533, Bradley–Terry 10.2307/2334029, AlphaStar 10.1038/s41586-019-1724-z, OpenAI Five 1912.06680, GT Sophy 10.1038/s41586-021-04357-7, Red Blob Games.

## Doubts / issues for other lanes

1. **`aside: Note` in `src/pages/works/[...slug].astro` is dead code.** MDX passes `components` only to markdown-generated elements; a literal `<aside>` stays a bare `<aside>` (no `role="note"`, Axe `landmark-complementary-is-top-level`, not in the aside column). The entry imports `Note` instead. Suggest removing the mapping or documenting it (A2 / I).
2. **`Stamp.astro` whitespace.** Its text is on its own line, so the span renders "\nas measured on … " and "(<Stamp/>)" prints as "( as measured on … )". A one-line span or `set:text` (as in `N.astro`) fixes it (A2-owned file; nit).
3. **Aside column gap at ≥ 1200 px.** The `Note` takes the grid row of the paragraph before it, so the text column shows empty space until the aside ends (about 350 px after the copy made it more compact). `grid-row: span 3` on `aside.note` would let the next paragraphs flow beside it (A2 / I; nit).
4. **AC1.7 overflow check vs KaTeX.** `.katex-mathml` (KaTeX's visually hidden MathML, 1 px clip) always has `scrollWidth > clientWidth`; lane I's AC1.7 test must skip it. An `aligned` environment also overhangs `.base` by 2 px (KaTeX's `.vlist-s` strut), which is why the PPO formula is two `$$` blocks.
5. **`astro preview` can background itself** (Astro 7.4.5 `cli/preview/index.js:37-45` auto-backgrounds in some environments, including this laptop's shells): Playwright's `webServer` then sees "exited early", or with `reuseExistingServer` silently reuses whatever daemon holds 4321 (a stale one from another worktree did, earlier today). Runs here used `ASTRO_PREVIEW_BACKGROUND=1`, which keeps the preview in the foreground so Playwright owns and stops it. Worth a line in the plan's build-lock command.
6. **Recipe hash is stale** for `tactical-arena`: the `stills` block is gone, so the stored recipe hash no longer matches; `check:media` does not compare recipe hashes (green), and the owner's next `media:encode` re-encodes the slug (spec P10-17, ADR 0052).
7. **The F1 marker reveals the pros' median before F4's guess.** Section 1 states the gap (STORY § 1) and F1 draws it, so section 6 says so and asks for the guess anyway, framed around the shape of the distribution.
8. The 3v3 utility and match numbers (`util.*`, `match.*`) are the 2026-10-25 3v3 agent, stamped as such; there are no 5v5 keys for them.
9. Lane N's note (D2 report): the copy uses both `measuredOn` dates as the facts carry them (11-04 for the reruns and the replay, 11-02 for the chain readout and holds); each stamp derives from the fact next to it.
