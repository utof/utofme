## Decisions and spec conflicts

1. **Marker `notebookId`.** The plan says to store the notebook id in the dataset module; the spec's `elo` whitelist row lists markers as `{abId, block, cs, lo, hi}`. The island needs the id to build `#nb-<id>`, so the shipped markers also carry `notebookId` (one extra short string each). Spec row should be amended.
2. **`after28[].game`** is a short public label from a literal map (`5v5 control`, `today's game`, `snap game`, `v3 game`, `crouch game`), not the notes' text, which names internal generator versions. The words for each row ("Snap fire", …) live in `elo-chart.ts`.
3. **Compiled set, block 2** is the anchor (0) with no interval, so the "three points with intervals" have intervals at blocks 10 and 28 only; the data row is `{block 2, v 0, lo 0, hi 0}`.
4. **Marker position:** markers sit on the active line (interpolated on the sparse compiled line), so the Try path works when compiled is selected. The two block-6 markers (flash arc, bot roles) are nudged 24 units apart.
5. **Layout:** the F3 keyframe and island share the same stage (CSS `aspect-ratio` 640:360, or 480:360 below 700 px = the spec's 4:3-ish phone layout) and the same drawing function, so hydration moves nothing. The `Figure` is given no `aspect`; the strip and 3v3 panel are static markup below the island.
6. F3 extras use plain `<p>` labels, not headings, so Axe's heading-order rule holds wherever the figure sits.
7. F9 nulls: CS maps, K = 1; kinds `same_seed` (the "keeps" and "changes" groups, 10 differences) and `indep_seed` (2 differences, the only independent-seed nulls with K = 1 in the source). Effects are all adopted (`kept`) A/B rows (46) of both eras.
8. F13 starts from fact `elo.head.block2`; percent is `formatPercent(winProbability(d), 0)` rounded once.
