# 0058 — Sight rule ported to TypeScript; the game is the oracle

Status: accepted (phase 10)

## Context

- F1 and F2 show what agents can see. The article's claim about the grid's extra sightlines is about the game's own rule, with the settings of the line the page shows: FOV 106°, no see-behind, directional "legs" smoke, range 10. The game code's older defaults (FOV 90° with see-behind) are not that game.
- The rule has a subtle part: 33 exact-integer samples rounded half up. It is not invariant under rotation or mirroring, so a "cleaner" port would disagree on edge cases.
- A figure that quietly differs from the game would undercut the article.

## Decision

`src/lib/sight.ts` ports the rule literally (`samplePoints`, `lineOfSight`, `canSee`, `smokeTiles`, `visiblePairs`) in the canonical `maps_cs` frame. `tests/fixtures/article/sight_parity.json` (200 cases, `verifiedAgainstGame: true`) is generated by the game's own functions on the owner's machine and is never edited; a mismatch is fixed in TypeScript. The parity test checks `lineOfSight` and `canSee` per case against the grids of the committed `maps_cs` output (`src/data/article/maps_cs.json`, the grids the page ships), and the map-independent half (cone and range, using the table's own `los`); all cases run in CI, none is skipped. If the game cannot run, the table falls back to 30 hand cases with `verifiedAgainstGame: false` and a mismatch becomes a caption fix, because F2 is illustrative.

## Alternatives

- **Bresenham or sub-tile ray casting.** Rejected: differs from the game on edge cases.
- **Hand-written expected values.** Rejected: they would encode our reading of the rule, not the game's behaviour.
- **Ship the game's code (WASM).** Rejected: size, and the game is not public.

## Consequences

- The fixture is test-only and never shipped.
- The map grids are not part of the table; the parity test reads them from the committed `maps_cs` output, so a re-sync of that dataset re-runs parity against the new grids.
- Any change to the head's settings requires regenerating the table.
