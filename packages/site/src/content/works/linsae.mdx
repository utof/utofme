A personal thinking tool. It starts as a Telegram-style feed of Markdown notes with `[[wikilinks]]`, then grows sideways: a canvas to place the notes on, a PDF reader that captures excerpts, and YouTube videos you can annotate at a timestamp. {/* src: README.md:3-6 */}

The notes are plain `.md` files on disk. SQLite with FTS5 is only an index, rebuilt from the files on every launch, so editing a note in another editor is supported. {/* src: README.md:8-11; README.md:20 */} It runs on Electron 42 and React 19, and reached version 0.8.1 in 702 commits. {/* src: README.md:28; package.json:3; git rev-list --count HEAD */}
