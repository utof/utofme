This project demonstrates how Expressive Code renders syntax-highlighted code blocks
on the site. The integration runs at build time via `astro-expressive-code`, producing
static HTML with embedded CSS for both light and dark themes — no client JS required
for the highlight itself.

The following snippet shows a minimal usage pattern. The `title="example.js"` directive
in the fence's meta-string drives EC's frame-title rendering; the copy button is enabled
globally via `ec.config.mjs`.

```js title="example.js"
// Why: demonstrate Expressive Code rendering with title and copy button
console.log("hello");
```

Each code block ships two theme variants (`github-light` and `github-dark`), toggled by
a `prefers-color-scheme` media query injected by EC. No JavaScript is needed to switch
themes — the browser applies the correct CSS block automatically.
