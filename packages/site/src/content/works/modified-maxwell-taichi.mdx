Electromagnetic waves, simulated live. The main app runs a 2D finite-difference time-domain (FDTD) solver on a 400×400 Yee grid with absorbing PML edges. {/* src: fdtd_2d_2.py:5; fdtd_2d_2.py:59-60 */} Drag the source, right-click to drop dielectric blocks, or press Tab for a 64³ 3D scene with a slotted metal slab and a dielectric sphere. {/* src: fdtd_2d_2.py:6-19; fdtd_2d_2.py:61 */} JAX runs the physics and pygfx draws it. {/* src: fdtd_2d_2.py:33-35 */}

A separate Taichi version on a 96³ grid cycles the update equations from normal to anisotropic to a flipped curl, which the code itself labels unstable. {/* src: test.py:12; test.py:39; test.py:57 */}
