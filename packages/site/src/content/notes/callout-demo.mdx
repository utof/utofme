Callouts use the Obsidian `> [!type]` syntax and are rendered with matching
CSS classes for visual emphasis.

> [!note]
> A callout body line. Notes highlight supplementary information inline.

> [!warning]
> Warning body. Warnings flag gotchas or things to double-check before acting.

The callout type becomes a CSS class (`callout-note`, `callout-warning`) so
each type can be styled independently via design tokens.
